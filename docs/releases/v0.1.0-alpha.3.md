This update fixes a crash when closing the Workshop project picker.

- Fixed UI pointer cleanup that could cause heap corruption during window
  teardown, including after opening the add-on manager.
- Picker crashes now report a launch failure and exit code instead of appearing
  as successful cancellation.
- Added regression coverage for pointer lifetime, copied guards and abnormal
  picker exits.

Close Workshop Tools, extract the new Windows x64 ZIP outside CS2, and start
its CMD launcher. Keep your custom add-on folders when updating. Existing
add-ons and the public SDK remain compatible.

The native logging provider remains disabled pending separate verification.
Automatic Hammer build-output capture continues to work independently.
