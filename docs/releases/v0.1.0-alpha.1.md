First public alpha of Hammer Addons for CS2 Workshop Tools.

Download **hammer-addons-v0.1.0-alpha.1-windows-x64.zip**, extract it outside CS2,
and double-click **Launch Workshop Tools.cmd**. Choose your project in Valve's
normal picker. The SDK archive contains C headers, example source, and documentation.

- Native add-on loader and shared manager for the project picker and editors.
- Panels, commands, settings, menu hooks, custom import handlers and editor metadata.
- Background jobs, cancellation and queued editor callbacks.
- Automatic Hammer build-output capture and the included Build log report.
  Open Help > Workshop Add-ons > Build log report and compile normally with F9.
- Tested native loader, launcher and Qt integration; real Hammer compilation and
  automatic report delivery verified on the supported CS2 build.

**Alpha limitations:** picker heap-corruption crashes have been observed and remain
under investigation. The separate native logging provider is disabled. Build-output
capture is independent of it, bounded, and may miss transient output. Diagnostics
are keyword candidates, not a build-success determination. No unsaved scene editing,
multiplayer editing, or radar generation is included in this release.

The portable launcher leaves the original game DLLs in place. Add-ons execute native
code with your account's permissions; install only trusted add-ons. The repository currently has
no license for its own code; third-party terms are documented separately.

SHA256SUMS.txt covers both downloads and release.json records the source commit.
