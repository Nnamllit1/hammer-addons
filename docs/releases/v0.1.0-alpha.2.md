This alpha adds project-aware diagnostics and session build history.

- **Problems table:** repeated build diagnostics are grouped, with first-line
  references, occurrence counts, original messages, and suggested checks for
  recognized resource and sound-operator errors. Zero failure counts are excluded.
- **Problem actions:** copy an asset path or diagnostic, and reveal an existing
  project-local source file in Explorer.
- **Build history:** view the latest eight captured builds and compare new/resolved
  messages between complete captures for the same editor window and map title.
- **Project context:** view the selected Workshop project's folders and find loose
  source files. The SDK exposes this through `hammer_project.h`.
- **SDK tables:** create selectable, read-only panel tables with stable row IDs.
  Example sources and the scaffold script include the new capabilities.
- Public installation and contributor documentation has been updated.

Download the Windows x64 ZIP, extract it outside CS2, and launch Workshop Tools
from its CMD file. In Hammer, open Help > Workshop Add-ons > Build log report
and build normally with F9. Close Workshop Tools before updating; keep any custom
add-on folders when transferring them to the new package.

**Known limitations:** picker heap-corruption crashes remain under investigation;
the native logging provider is disabled. Capture can be partial, and history lasts
only for the current session. Source lookup checks loose files in the selected
project, not VPKs or the full asset dependency graph. Editor context does not expose
unsaved map objects. Radar generation is not included.

Regression coverage includes project-path validation, SDK compatibility, diagnostic
classification, build comparisons, table selection, and the existing loader/UI tests.
