Add launcher compatibility with **CS2 build 25640462**. Update the complete
portable package if the launcher rejects Asset Browser after this CS2 update.

## Changes

- Added the new Valve-signed Asset Browser binary after verifying its x64
  architecture and all six required exports and ordinals.
- Retained support for previously inspected builds. Steam and Qt binaries in
  this installation are unchanged from the previous compatibility update.
- No SDK or add-on lifecycle changes.

## Update

Close Workshop Tools and the project picker, then extract
**hammer-addons-v0.1.0-alpha.6-windows-x64.zip** into a new folder outside CS2.
Copy your custom add-ons into its `addons/` folder, keeping the updated bundled
files. Start **Launch Workshop Tools.cmd** and update existing shortcuts to the
new location.

Compatibility profiles are compiled into the launcher. Editing a JSON file
beside an older executable does not update it. No Valve DLL replacement is needed.

## Known limitations

A Microsoft Defender detection of `tools_launcher.exe` has been reported
(`Behavior:Win32/DefenseEvasion.A!ml`). This compatibility update does not resolve
that report or establish that it is a false positive. If protection blocks the
launcher, leave the protection enabled rather than adding an exclusion.

The release workflow builds and tests the tagged source before publishing.
A live editor session on build 25640462 has not been verified. Native add-ons
remain unsandboxed, and the native tool-log provider remains disabled.
